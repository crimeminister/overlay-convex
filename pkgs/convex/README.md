# Convex (Decentralized Lattice Network)

Nix package definition and NixOS module for [Convex](https://convex.world), a decentralized, lattice-based network and execution platform for the "Internet of Value".

This package builds the unified standalone Convex executable from the [Convex-Dev/convex](https://github.com/Convex-Dev/convex) monorepo.

## Installation

### Using in a Nix Shell

To run the Convex CLI directly without a permanent installation:

```bash
nix-shell -p 'let pkgs = import <nixpkgs> { overlays = [ (import ./default.nix) ]; }; in pkgs.convex'
```

### Adding to NixOS / Home Manager Configuration

Add the overlay to your Nixpkgs configuration and include `convex` in your environment packages:

```nix
{ pkgs, ... }:

{
  nixpkgs.overlays = [
    (import ./path/to/ai-overlay/default.nix)
  ];

  environment.systemPackages = [
    pkgs.convex
  ];
}
```

## NixOS Module

This overlay includes a NixOS module to configure and run Convex as a system service.

### Importing the Module

To use the module, import it in your NixOS configuration from the overlay package:

```nix
{ config, pkgs, ... }:

{
  imports = [
    pkgs.convex.module
  ];
}
```

### Configuration Example

Here is a typical configuration running a Convex Peer node as a system service:

```nix
{ config, pkgs, ... }:

{
  imports = [ pkgs.convex.module ];

  services.convex = {
    enable = true;

    # Configure ports
    peerPort = 18888;
    apiPort = 8080;

    # Passwords for keystore integrity and keys (highly recommended to use EnvironmentFile)
    secretsFile = "/etc/convex/secrets";

    # Automatic bootstrapping on first startup
    bootstrap = {
      mode = "genesis"; # or "create" to join an existing peer
      governanceKey = "0x..."; # optional genesis governance key
      storepassFile = "/etc/convex/storepass";
      keypassFile = "/etc/convex/keypass";
    };
  };
}
```

Make sure the secrets file `/etc/convex/secrets` is owned by `convex:convex` (mode `600`) and contains the environment variables:

```ini
CONVEX_KEYSTORE_PASSWORD=mykeystorepassword
CONVEX_KEY_PASSWORD=mykeypassword
CONVEX_PEER_KEY_PASSWORD=mypeerkeypassword
```

## Usage

The package exposes a single unified `convex` command.
You can view all available operations by running:

```bash
convex --help
```

### Available Commands

- **`peer`**: Start, stop, or operate a Convex network Peer (validating node).
- **`local`**: Launch a local test network for CVM development and smart contract simulation.
- **`desktop`**: Run the Convex desktop graphical user interface.
- **`key`**: Manage cryptographic keys and key stores (PKCS #12 formats).
- **`account`**: Interact with and manage Convex accounts on the network.
- **`query` / `transact`**: Run queries or submit state-changing transactions to a peer.
- **`dlfs`**: Spin up or manage a Data Lattice File System (DLFS) node.
- **`etch`**: Interact with the local high-performance Etch database.

### Running a Local Development Network

To start a single-node sandbox network for testing:

```bash
convex local start
```

## Technical Details

- **Language Support:** Compiled using Java 21 via Maven.
- **Dependency Locking:** All Maven dependencies (including offline compile/assembly plugins) are locked and verified in a Fixed-Output Derivation (`mvnHash`) to guarantee build reproducibility.
- **Repackaging:** The build is customized via `overrideAttrs` to invoke the `install` phase of Maven, which runs the `maven-assembly-plugin` to produce the unified runnable `convex.jar` file.
- **Runner wrapping:** The binary path `/bin/convex` is a shell wrapper generated by `makeWrapper` that invokes the Java Runtime Environment (`jre`) pointing to the compiled fat JAR.
